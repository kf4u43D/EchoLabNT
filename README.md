# EchoLabNT

Stereo delay for disting NT, built around the colour and character of inserts in the feedback loop. Saturation, filtering, modulation and grain reshape the echoes on each pass, from warm repeats to rough, evolving textures.

20 treatments and 21 presets, with CV modulation and MIDI/CV clock sync. Some demo presets can get a little wild; adjust them to taste.

**[Download 0.7.1-rc.5](https://github.com/kf4u43D/EchoLabNT/releases/download/v0.7.1-rc.5/EchoLabNT-public-0.7.1-rc.5.zip)** · [Release notes](https://github.com/kf4u43D/EchoLabNT/releases/tag/v0.7.1-rc.5)

Target: **firmware 1.18.0 / API 13** · **Prerelease**

Back up your presets and plug-in files. With the NT powered off, copy `echolabnt.o` to `/programs/plug-ins/` on its MicroSD card, keeping a single copy of the algorithm. Safely eject the card, reinsert it and restart.
