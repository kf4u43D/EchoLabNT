# EchoLabNT

Stereo delay for Expert Sleepers disting NT: 20 treatments, 21 presets, CV modulation and MIDI/CV clock sync.

**[Download 0.7.1-rc.5](https://github.com/kf4u43D/EchoLabNT/releases/download/v0.7.1-rc.5/EchoLabNT-public-0.7.1-rc.5.zip)** · [Release notes](https://github.com/kf4u43D/EchoLabNT/releases/tag/v0.7.1-rc.5)

Target: firmware **1.18.0 / API 13**. Current version: **prerelease**.

## Install

1. Download and extract the ZIP. Back up your presets and plug-in files.
2. Power off the NT and copy `echolabnt.o` to `/programs/plug-ins/` on its MicroSD card. Replace older copies, including `coloured_echos.o` or `echo_lab_nt.o`; keep backups outside that folder tree.
3. Safely eject the card, return it to the NT and restart. Add **EchoLabNT**, choose a preset, then adjust Time, Feedback and Mix.

New instances start on **Analog Bounce** at 120 BPM.
